# How to run

make the environmwnt:

`python -m venv env`

for linux:
`source env/bin/activate`

install requirements:
`pip install -r requirements.txt`

move to the project root:
`cd data_agent`

run the project:

`python manage.py runserver 8001`

in the browser (chrome or firefox) go to:

`http://127.0.0.1:8001`


your agent should run on the `http://127.0.0.1:8888/ask`
